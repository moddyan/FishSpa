# 设计方向决策 - 2026-08-13

## 当前方向

- 当前推进的是 3D 单人版本：第一人称、低压力、关卡制的海洋生物清洁与护理模拟。
- 玩家是一条游戏化的清洁鱼，以生物能力为基础，后续可自然加入天然材料或来自人类世界的轻型工具。
- 游戏不限于口腔清洁。最初的两张核心画面是“清理鲨鱼口腔”和“清理海龟藤壶”。
- 内容结构按“目标动物 × 身体区域 × 问题类型”扩展。
- 基础玩法由连续清洁与块状问题处理共同构成；工具只是擦除、啄取、拉扯、解缠、冲洗等基础动作的不同实现。

## 原型决策

- 旧第三人称鲸鱼口腔原型停止扩展。冲刺、舌头危险、闭嘴倒计时和撤离循环不属于当前方向。
- 新原型是“海龟护理交互实验室”，先验证第一人称水下移动、连续污垢清洁和藤壶拔除。
- 海龟实验通过后，再用鲨鱼口腔验证同一套清洁语言能否适应封闭空间和不同身体结构。
- 2D 俯视角多人合作版本被视为另一个独立游戏，不纳入当前项目范围。

## 当前技术状态

连续污垢遮罩、曲面笔刷、清洁进度、近表面作业辅助和藤壶拉扯方案尚未确定，需要单独讨论后再实现。
